# Exclusive media sources

Place original video and audio exports in this folder for review and optimization.
Use descriptive filenames, such as `exclusive-segment-title-uhd.mp4`.

Media in this folder is excluded from Git and the website build. Keep a backup
of your originals. Optimized copies can be prepared alongside the originals
and uploaded separately to the `exclusives/` folder in the
`water-valley-voice-media` Cloudflare R2 bucket.

Published copies are served from `https://media.watervalleyvoice.com/exclusives/`.
See [the R2 media guide](../docs/r2-media.md) for setup and upload details.

Each Exclusive can stand alone. When one relates to an existing episode,
provide that episode along with the Exclusive's title and description.
